# Saudi Dialect to Modern Standard Arabic — Overleaf Project

1. Upload this ZIP to https://www.overleaf.com/ as a New Project / Upload Project.
2. In Menu, select **pdfLaTeX** if the project does not compile automatically.
3. The main file is `main.tex`; edit names, wording or date there if necessary.
4. Compile to obtain the one-page A4 project proposal. The existing `preview.pdf` was compiled from this source for checking.

This proposal records 100 team-approved messages and a planned GitHub freeze; it does not claim training or evaluation of the real model has been completed.
